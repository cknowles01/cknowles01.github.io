# Connor Knowles - Academic Website

A modern, responsive personal academic website built with Astro, TypeScript, and Tailwind CSS. Optimized for GitHub Pages deployment.

## 🚀 Tech Stack

- **Framework:** Astro 4.x
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Content:** MDX support
- **Deployment:** GitHub Pages

## 📦 Features

- ✨ Modern, clean design with dark/light theme toggle
- 📱 Fully responsive across all devices
- ⚡ Lightning-fast static site generation
- 🎨 Tailwind CSS for styling
- 🌙 Dark mode support
- 📊 Project showcase with filtering
- 📧 Contact page with social links
- 🏆 Honors and timeline sections
- ♿ Accessible and SEO-optimized
